OpenAI 流式語音轉文本服務

基於 OpenAI API 的實時語音轉文本解決方案，支援批處理與流式處理

專案概述

這個專案是一個使用 OpenAI API 將語音實時轉換為文本的服務，包含兩個主要功能：文件批處理轉錄和實時流式轉錄。專案採用 Python 開發，並提供了 Web 界面供用戶互動。

文件轉錄

適用於預先錄製的音訊檔案，支援指定模型、語言提示和特定詞彙辨識率提升功能。

實時流式轉錄

通過 WebSocket 實現實時語音識別，支援多客戶端同時連接，即時返回轉錄結果。

技術細節

OpenAI API 使用

專案使用了 OpenAI 的兩種 API：

1. 文件轉錄 API

# streaming_transcription.py
stream = self.client.audio.transcriptions.create(**params)

用於處理上傳的音訊檔案，支援多種參數配置

2. 實時 WebSocket API

# realtime_transcription_service.py
OPENAI_WSS_URL = "wss://api.openai.com/v1/realtime?intent=transcription"

用於實時串流轉錄，支援連續音訊資料處理

WebSocket 通訊

專案實現了三層 WebSocket 通訊：

通訊層 描述 實現方式
瀏覽器 <-> Web 服務器 客戶端與 Web 服務器的通訊 瀏覽器 WebSocket API 和 aiohttp
Web 服務器 <-> 轉錄服務 Web 代理與轉錄服務的通訊 aiohttp 和 websockets 庫
轉錄服務 <-> OpenAI API 轉錄服務與 OpenAI API 的通訊 websockets 庫

部署指南

系統要求

  • Python 3.7+
  • 主要依賴套件：
    • openai: OpenAI 客戶端庫
    • aiohttp: 異步 HTTP 客戶端/服務器
    • websockets: WebSocket 客戶端/服務器
    • asyncio: 異步 I/O 支援
    • python-dotenv: 環境變數管理

快速開始

1. 安裝依賴：
pip install aiohttp websockets asyncio python-dotenv openai
2. 設置 API 密鑰（可選）：
export OPENAI_API_KEY='your-api-key'
3. 啟動服務：
python start_service.py
4. 訪問 Web 界面：
http://localhost:8080

高級配置

自定義端口和主機

python start_service.py --host 127.0.0.1 --web-port 8088 --ws-port 8766

python start_service.py --debug

python start_service.py --ssl-cert /path/to/cert.pem --ssl-key /path/to/key.pem

指定 OpenAI API 密鑰

核心組件分析

1. 文件轉錄 (streaming_transcription.py)

這個模組提供了對預先錄製音訊檔案進行轉錄的功能：

文件轉錄類
class StreamingTranscriber:
    def __init__(self, api_key=None):
        """初始化 OpenAI 客戶端"""
        
    def transcribe_file(self, audio_path, model="gpt-4o-mini-transcribe", prompt=None, language=None):
        """對一個音訊檔案進行流式轉錄"""
        
    def save_transcription(self, text, output_path):
        """將轉錄結果保存到文件"""

關鍵特性：

  • 支援流式處理，即邊處理邊輸出結果
  • 支援指定轉錄模型，提供語言提示和特定詞彙輔助
  • 支援設置特定語言以提高識別準確度
  • 能夠保存轉錄結果到文件

2. 實時轉錄服務 (realtime_transcription_service.py)

這是專案的核心組件，實現了通過 WebSocket 連接 OpenAI 的實時轉錄 API：

實時轉錄服務關鍵函數
async def handle_client(websocket, path):
    """處理客戶端連接"""
    
async def init_openai_connection(client_ws, api_key, session_id, language=None):
    """初始化與 OpenAI 的 WebSocket 連接"""
    
async def handle_openai_messages(openai_ws, client_ws, session_id):
    """處理來自 OpenAI WebSocket 的消息並轉發給客戶端"""

工作流程：

  1. 客戶端通過 WebSocket 連接到服務
  2. 客戶端發送初始化請求（包含 API 密鑰和可選語言設置）
  3. 服務器與 OpenAI 建立 WebSocket 連接
  4. 客戶端發送音訊數據
  5. 服務器將音訊數據轉發到 OpenAI
  6. OpenAI 處理並返回轉錄結果
  7. 服務器將結果轉發給客戶端

關鍵特性：

  • 支援多客戶端同時連接（使用會話 ID 管理）
  • 支援配置多種參數（語言、模型等）
  • 實時轉發音訊數據和轉錄結果
  • 支援結束會話和清理資源
